- **Data:** MySQL, SQL Server, PostgreSQL with pgvector, ETL pipelines, Power BI
- **AI:** Python, PyTorch, Hugging Face, LangChain, RAG, FastAPI, Spring AI
- **Frontend:** React, plus TypeScript and Next.js when a project needs it

Before these repositories I built a school administration system, a hotel management application, and ETL
